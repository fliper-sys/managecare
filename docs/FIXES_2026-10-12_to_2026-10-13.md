# Fix Log: 2026-10-12 to 2026-10-13

This log summarizes fixes recorded in the active ManageCare work session for October 12-13, 2026. It is not a complete audit of every modified file in the working tree; unrelated and pre-existing changes are intentionally excluded.

## 2026-10-13

### Administrative dashboard and flows

- Refreshed the Administrative Dashboard with ManageCare colors, clearer summary tiles, loading animation, and improved quick-action and navigation surfaces.
- Made Revenue and Expenses summary tiles navigate to Finance, Clients navigate to the client list, and Total Staff navigate to Staffing.
- Removed sales-oriented quick stats and date filtering for administrative businesses on the owner dashboard. Added a shortcut to the Administrative Work dashboard and skipped sales/customer metric requests for that business type.
- Fixed task opening for owners/managers: only the task's assigned worker starts a task or submits work. Other viewers see an explanatory notice instead of a failed start request.
- Fixed async `setState` callbacks in security, client details, task comments/records, calendar, staffing, activity, finance, and invoice flows. These callbacks assigned `Future` values and could throw at runtime.
- Improved portal credential entry with six-digit passcode validation, required-field and length validation, save progress feedback, and a security-summary refresh after saving.

### Document folder counts

- Updated `GET /administrative/:businessId/clients/:clientId/folders` to include each folder's related document count as `document_count`, preserving the existing response structure and pagination.
- No database migration is required. The server change is **not deployed**; existing app versions will receive the counts after the backend route is deployed and restarted.
