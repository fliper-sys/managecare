# Agriculture (Poultry & Livestock) Features

This module provides simple farm management features focusing on livestock and poultry production metrics.

Implemented features:
- Add livestock groups (type, name, count, age weeks, maturity week, feed per bird)
- Per-group daily feed calculation (kg/day)
- Record daily egg production and view recent records
- Dashboard integration and livestock list with quick stats
- Small unit tests for feed calculation and egg averages

Next improvements:
- Persist groups to backend (FireStore) via repository
- Add charts for egg production and feed usage
- Add mortality and feed consumption logs
- Add per-bird records and batch operations
