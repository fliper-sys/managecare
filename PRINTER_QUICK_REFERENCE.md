# Printer Support - Quick Reference Card

## 📋 Overview

Manage Care now supports both **USB** and **Bluetooth** thermal printers for receipt printing.

---

## 🖨️ Printer Types

### USB Printer (Web Only)
**Model**: Xprinter XP-58  
**Platform**: Web (Chrome/Edge)  
**Setup Time**: 2-5 minutes  
**Typical Cost**: $80-120  

**Pros**:
- ✅ Faster print speed
- ✅ Reliable connection
- ✅ No batteries needed
- ✅ Professional quality

**Cons**:
- ❌ Web only (Chrome/Edge)
- ❌ Requires HTTPS
- ❌ USB cable required

---

### Bluetooth Printer
**Model**: Any Bluetooth thermal printer  
**Platform**: Mobile/Desktop  
**Setup Time**: 5-10 minutes  
**Typical Cost**: $100-200  

**Pros**:
- ✅ Works on mobile
- ✅ Wireless freedom
- ✅ Portable
- ✅ Any platform

**Cons**:
- ⚠️ Limited range (~10m)
- ⚠️ Battery required
- ⚠️ Pairing needed
- ⚠️ Slower connection

---

## ⚙️ Quick Setup

### USB Printer (Chrome/Edge Web)

```
1. Settings → Printer Settings
2. Select "USB" connection
3. Click "Pair USB Printer"
4. Select XP-58 from browser picker
5. Click "Test USB Printer"
6. Verify receipt prints
```

**Time**: ~2 minutes

---

### Bluetooth Printer (Mobile/Desktop)

```
1. Pair printer in device Bluetooth settings
2. Settings → Printer Settings
3. Select "Bluetooth" connection
4. Click "Pair Bluetooth Printer"
5. Select printer from list
6. Click "Test Bluetooth Printer"
7. Verify receipt prints
```

**Time**: ~5 minutes

## 🚨 Common Errors & Quick Fixes

### "USB Access Denied"
**Fix**: Click "Pair USB Printer" again, grant permission

### "No Bluetooth printer found"
**Fix**: Pair printer in phone Bluetooth settings first

### "Cannot reach printer"
**Fix**: Power on printer, move closer, try again

### "WebUSB not available"
**Fix**: Use Chrome/Edge on HTTPS, not Firefox/Safari

### "Device not found"
**Fix**: Reconnect USB cable or restart printer
